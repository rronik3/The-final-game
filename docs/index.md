# Розробка гри "Apple Quest" 🍎

Кваліфікаційна робота на підтвердження ступеня фахового молодшого
бакалавра ([ВСП «ППФК НТУ «ХПІ»](http://polytechnic.poltava.ua)).

Керівник
роботи – **Бабич Олександр Вікторович**.

## 📚 Завдання до дипломної роботи
Продукт має являти собою гру, побудовану з використанням рушія Unreal Engine. За сюжетом гри, гравець подорожує світом, б’ється з ворогами, і збирає чарівні яблука, які грають роль внутрішньоігрової валюти. Слід подбати про мінімалістичний, але зручний
інтерфейс користувача, зручне керування персонажем, приємний візуальний стиль гри. Готовий продукт повинен мати хоча б один закінчений рівень з можливістю експорту (картинка чи PDF) яскравої «картки досягнення», на якій вказані дата, час, та кількість яблук, зібраних гравцем.

## 🛠️ Використані технології

- **Unreal Engine**
- **Blueprint Visual Scripting**
- **3D-моделі та матеріали**
- **HUD через Widget Blueprint**
